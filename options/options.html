Rules

How rules work
  • Each category is checked on its own. Inside a category the first matching rule wins, so keep specific rules (DDP5.1 Atmos) above general ones (DDP5.1). Drag order with ↑ ↓.
  • Verdict: any category rated red makes the release red. All rated categories green make it green. Anything else is yellow.
  • If not found decides what happens when no rule in the category matches: ignore it, treat as yellow, or treat as red.
  • Patterns: comma separates alternatives. & means all terms must be present, ! means must be absent: REMUX & DV, 2.0 & !5.1. Separators are loose, so WEB-DL also matches WEBDL, WEB.DL and WEB DL. Case doesn't matter.
  • For anything else, write a regular expression between slashes: /ddp?5\.1/.
